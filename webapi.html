JSON Rules

Important rules that must be adheared to in order to create a valad JSON data:

Objects

Enclosed in curly braces {} and contain comma-separated key/value pairs.

{ "name": "John", "age": 30 }

Keys

Must be strings enclosed in double quotes (e.g., "name": "John")..

( "name": "John" )

Values:

Can only be a string, number, object, array, boolean (true/false), or null. Functions and undefined are not allowed

"name", "1", ( "names"), [1,2,3], "true"

Arrays:

Enclosed in square brackets [] and contain an ordered list of values.• Trailing Commas: Not allowed at the end of a list or object.

[1, 2, 3]

Trailing Commas:

Not allowed at the end of a list or object.

{ "name": "John", "age": 30, }

Strings use double quotes only

no single quotes anywhere

"name": "John"
